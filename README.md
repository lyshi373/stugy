# 学习打卡中心 · 多软件自学打卡系统

基于 B站教程的多软件自学打卡系统，内置 UG NX 12.0、数字化入门、DJI Action 4、SolidWorks、Excel、游泳等学习模块，也支持自定义创建任意课程的打卡计划。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | **主入口** - 首页、软件打卡（通用引擎）、知识点汇总、「如何新增」说明页、下载到手机 |
| `template.html` | 通用打卡模板（DJI Action 4 / 游泳 / 自定义软件使用） |
| `modules/` | **每个软件一个文件**，存放该软件的学习内容与配置（详见下文「模块化」） |
| `tools/` | 开发测试工具：`test_app.js`（36项功能回归）、`verify_modules.js`（模块数据一致性校验） |
| `manifest.json` | PWA 应用配置文件 |
| `sw.js` | Service Worker（离线缓存） |
| `make_zip.py` | 打包工具（生成 ZIP 方便传到手机） |
| `打包.bat` | 双击运行打包工具 |

## 模块化结构（重点）

所有软件的学习内容都独立存放在 `modules/` 目录，**主程序不直接写死任何课程数据**：

| 文件 | 软件 | 类型 |
|------|------|------|
| `modules/ug-nx12.js` | UG NX 12.0 | 内嵌打卡（主程序内日历） |
| `modules/digital-basics.js` | 数字化入门 | 内嵌打卡（主程序内日历） |
| `modules/dji-action4.js` | DJI Action 4 | 通用模板（template.html） |
| `modules/solidworks.js` | SolidWorks | 通用模板（template.html） |
| `modules/excel.js` | Excel | 通用模板（template.html） |
| `modules/swimming.js` | 游泳 Swimming | 通用模板（template.html） |

### 修改某个软件的学习内容

只改 `modules/` 下对应文件即可，无需动主程序：

1. `embeddedPlan`：内嵌打卡用的每日计划（含学习目标、学习要点、视频、知识点）
2. `templatePlan`：通用模板（template.html）用的每日计划
3. `knowledgePreset`：知识点汇总页的数据（内嵌模块可省略，会自动由 embeddedPlan 生成）
4. 修改后把 `planVersion` 递增（如 `v2` → `v3`），浏览器会自动更新学习计划，**已打卡记录和笔记不会丢**

### 新增一个内嵌打卡软件（如 UG 那样带日历的模块）

1. 在 `modules/` 新建 `xxx.js`，参照 `modules/digital-basics.js`：
   - `type: "builtin"`
   - `engine` 里指定 `viewId`（如 `view-xxx`）和 `domPrefix`（如 `xxx`）
   - `embeddedPlan` 填每日计划
2. 在 `index.html` 里复制一份打卡视图 HTML（参照 `view-digital`），把 id 前缀换成 `domPrefix`
3. 把软件 id 加进 `index.html` 顶部的 `DEFAULT_SOFTWARE_IDS` / `EXTENDED_SOFTWARE_IDS`
4. 主程序会自动注册视图、渲染日历、加载知识点

### 新增一个模板型软件（走 template.html）

1. 在 `modules/` 新建 `xxx.js`，参照 `modules/dji-action4.js`：
   - `type: "template"`，提供 `templatePlan` 和 `knowledgePreset`
2. 在 `index.html` 顶部的 `DEFAULT_SOFTWARE_IDS` / `EXTENDED_SOFTWARE_IDS` 加上该软件 id，首页即出现卡片

> 如需调整首页展示顺序，修改 `index.html` 顶部的 `DEFAULT_SOFTWARE_IDS` 即可。

## 快速开始

### 电脑使用

双击 `index.html` 用浏览器打开即可。打卡、笔记、编辑功能正常使用。

### 在线访问（GitHub Pages）

无需下载，直接打开：**https://lyshi373.github.io/stugy/** 。代码推送到 GitHub 后 1-2 分钟自动部署，如看到旧内容请按 `Ctrl+F5` 强制刷新。

### 手机使用（下载到手机）

无需电脑开服务器，只需三步：

1. **打包**：在电脑上运行 `python make_zip.py` 生成 `学习打卡中心.zip`
2. **传输**：把 ZIP 文件通过微信/QQ/数据线传到手机，解压
3. **添加到主屏幕**：用 Edge（安卓）或 Safari（苹果）打开 `index.html` → 点菜单 → 添加到主屏幕

> 💡 **手机端视频播放**：手机端自动显示「📱 在B站App中打开」按钮，点击直接唤起已安装的 bilibili App 播放，无需服务器。

详细步骤请打开在线网址后，点击底部「📖 如何新增」查看「📱 添加到手机屏幕」教程（安卓/苹果各有步骤说明）。

## 功能介绍

### 打卡中心首页
- 底部导航三个入口：**首页**（打卡中心）/ **知识点**（全部软件知识点汇总）/ **如何新增**（新增项目图文教程）
- 多软件卡片管理（数字化入门、Excel、游泳、自定义软件等；UG / DJI / SolidWorks 默认隐藏）
- **访问控制**：UG / DJI / SolidWorks 默认不显示；Excel 点击需输入密码（默认 123456，可在 `index.html` 顶部 `PASSWORD_SOFTWARE` 修改）
- 每个软件独立进度条
- 可添加/删除自定义软件
- 删除软件后统一进入回收站：通过右下角橙色「恢复」悬浮按钮找回，支持单个恢复、全部恢复、单个彻底删除、全部彻底删除
- 自定义软件删除后**打卡数据和编辑的教程内容会完整保留**，恢复时一键还原到原状态

### 两种打卡模式
- **学习模式**：看视频、学知识点、写笔记、完成打卡（30字限制）
- **编辑模式**：自己填入每天的学习目标、B站视频链接、知识点列表

### 核心功能
- **按天解锁**：完成前一天打卡才能开启下一天
- **30字打卡限制**：必须输入至少30字学习笔记才能完成打卡
- **Word 导出**：单日导出 / 全集导出学习笔记
- **本地存储**：数据保存在浏览器，关闭后进度保留
- **PWA 支持**：可添加到手机主屏幕，离线可用
- **响应式设计**：手机/平板/电脑自适应

### 教程管理（一键更换教程）

在打卡页面的「编辑模式」→ DAY 1 顶部，提供整套教程的管理功能：

- **📤 导出教程**：将当前编辑的整套教程导出为 JSON 文件，方便备份或分享
- **📥 导入教程**：从 JSON 文件一键导入教程
- **📋 套用模板**：内置多个预设学习框架（7/10/21天，CAD基础，办公软件等）

## 常见问题

**Q：B站视频无法内嵌播放？**
A：电脑端用浏览器打开 index.html 即可内嵌播放；手机端自动切换为「唤起B站App」模式。

**Q：手机端看视频需要电脑开服务器吗？**
A：不需要。手机端检测到移动环境后会显示「📱 在B站App中打开」按钮，直接唤起 bilibili App 播放。

**Q：手机和电脑的数据互通吗？**
A：不互通。数据存储在各自浏览器的 localStorage 中。可通过「教程管理 → 导出/导入 JSON」转移教程内容。

**Q：如何重置进度？**
A：在打卡页面顶部点击「重置」按钮（编辑的内容不会丢失，仅清空打卡记录）。

**Q：DJI Action 4 的视频 BV 号不全怎么办？**
A：Day2/Day4/Day5 中的视频位置标注了 B站搜索关键词，复制关键词到 B站搜索即可找到对应视频，获取 BV 号后在「编辑模式」填入即可正常播放。

**Q：想换掉内置模块的视频（BV号）？**
A：内置模块（UG、数字化入门等）的视频在 `modules/` 对应文件里，把该视频的 `bvid` 换成新 BV 号，再把 `planVersion` 递增（如 v2 → v3），刷新页面即可生效，已打卡记录与笔记不受影响。自定义项目直接在「编辑模式」改即可。

**Q：误删了软件模块/自定义打卡计划怎么办？**
A：删除任何模块（内置模块或自定义软件）后，页面右下角都会出现橙色「恢复」悬浮按钮。点击后打开恢复面板：
- 自定义软件会标注「（自定义）」字样，恢复时会**完整还原打卡记录、编辑的教程内容、天数、颜色等所有配置**
- 可单个点击「恢复」，也可点击底部「恢复全部」
- 确定不再需要的模块，点击「彻底删除」或「彻底删除全部」，彻底删除后不再出现在恢复列表中

**Q：彻底删除后还能找回模块吗？**
A：不能。彻底删除会：
- 内置模块：加入永久删除名单，刷新后也不会自动恢复
- 自定义软件：从回收站清除元信息和打卡数据，浏览器 localStorage 中不再保留备份

如需恢复，只能清除浏览器站点数据（会丢失所有打卡记录和教程配置）。

**Q：多个视频同时播放怎么办？**
A：系统已修复此问题，采用**单 iframe 方案**：
- 电脑端每天只渲染一个视频播放器（iframe）
- 其他视频显示为可点击的切换按钮
- 点击切换视频时，旧视频会自动停止
- 关闭弹窗时，视频会完全停止（将 src 设为 about:blank）

**Q：修改学习天数后，学习计划内容没有正确分配怎么办？**
A：系统已修复此问题，采用**均匀分配策略**：
- 无论设置多少天，内容总量保持不变，只是每天分配的数量不同
- 系统会将所有视频和知识点平均分配到每一天
- 示例（36节课）：18天→每天2节，36天→每天1节，25天→11天2节+14天1节

## 视频播放控制说明

### 单 iframe 方案
- **电脑端**：每天只渲染一个 `<iframe>`，id 为 `main-video-iframe`（template.html）或 `ug-main-video-iframe`（index.html）
- **手机端**：自动切换为「唤起B站App」模式
- **切换视频**：通过修改唯一 iframe 的 `src` 属性实现，不会创建新的播放器
- **停止视频**：关闭弹窗时调用 `stopAllVideos()` 函数，将 iframe 的 `src` 设为 `about:blank`

### 视频 URL 参数
- 默认不自动播放：`&autoplay=0`
- 切换时自动播放：`&autoplay=1`

## 学习计划天数调整说明

### redistributePlan 函数
位置：template.html 第 982-1078 行

**功能**：当用户修改学习天数时，均匀重新分配每天的视频和知识点内容

**策略**：均匀分配策略
1. **数据源**：`_content`（用户编辑过）→ `PRESET_PLANS`（内置预填充）
2. **扁平化**：将所有视频和知识点扁平化成列表
3. **平均分配**：使用 `distributeEvenly()` 函数平均分配到每一天
   - 算法：前 `remainder` 天多分配一个，确保分配尽可能均匀
   - 公式：`base = Math.floor(total / days)`，`remainder = total % days`

**示例**（36节课）：
- 18天：base=2, remainder=0 → 每天 2 节
- 36天：base=1, remainder=0 → 每天 1 节
- 25天：base=1, remainder=11 → 11天 2 节 + 14天 1 节
